# 当场回应 · 「水果为什么会腐烂？」

> 孩子 5 岁（大班），可以说两步。下面这几句现在就能对他说。

## 1. 现在就能说的真回答（两步）

「水果上和空气里，住着好多小到看不见的小家伙——霉菌和细菌。它们最爱吃水果里甜甜的汁，一边吃一边把水果弄软、弄出怪味道，这就是腐烂。」

如果他接着问「它们从哪儿进去的」：

「水果皮就像房子的墙。墙一破（碰伤了、裂开了），小家伙就从破口钻进去，坏得特别快。」

## 2. 现在就能做的小动作

- 去厨房找一找：有没有哪个水果身上有软软的、颜色变深的地方？让他看看那块是不是正好在**磕碰过、破了皮**的地方。
- 只看、不吃，也别凑近闻发霉的地方，看完洗手。
- 想多玩一点：切开一个苹果，一半马上放回冰箱、一半放在桌上，明天一起看看哪一半变黄得更厉害（变黄主要是切面碰到空气，不是腐烂，但能让他看到「放在哪儿不一样」）。

## 3. 一句备用的话

如果他问到你答不上来的地方：「这个我也不知道，我们一起查。」
大人说不知道，孩子以后照样信你；乱猜说错了，他才会不信。

## 4. 要不要做成一本书？

如果他听完已经满意了，就不用做。
如果他追着问、你想讲得更透、或者想留作纪念，告诉我，我把它做成一本绘本，你先看过再给他读。

---

**家长回复：**「他听完又问为什么冰箱里的不容易坏，做成书吧。」
→ 进入做书流程。冰箱这个追问是当场冒出来的（还没有上一本书），所以按**新问题**做，把「为什么冰箱里的不容易坏」写进书里第三章「回到生活」。
