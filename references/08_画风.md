# 08 · 画风（风格卡）

> 什么时候读：第 6 步出画面之前；问卷第 7 题让家长选画风时。
> 原则：**出图的形式可以不同，审美要统一。** 这份风格卡像建筑的设计导则：规定调色、线条、构图和禁止项，不规定每一页画什么。不管是能生图的 agent，还是只能写代码的 agent，出来的书都应该一看就是同一家人。
> 每种风格都有一张 2026-10-11 实测的小样，在 `assets/styles/`。画之前先看一眼对应的小样。

## 一、所有风格共用的约束

**视觉签名：拆解图。** 这个方法的核心是「走进去、剖开看、回到生活」，画面语言也跟着走：剖面（把东西切开看里面）、放大圈（细线连到要看的地方）、轴测和小房间。不是每页都要用，但讲「里面是什么、怎么工作」的那几页，优先用这几种画法。

**调色**：暖、浅、克制。纸色底（象牙白 `#FBF6EC` 一类），主色不超过 5 种，饱和度中低。参考色：

| 用途 | 参考色 |
|---|---|
| 纸 / 底 | `#FBF6EC` 象牙白、`#F4EBDD` 米色 |
| 线 | `#4A3B2C` 深褐（不用纯黑） |
| 暖红 | `#D9584E` |
| 淡黄 | `#F2D38E` |
| 草绿 | `#7FA86A` |
| 天蓝 | `#6E9FD6` |
| 向导小方 | 橙 `#F08A2C`、黄帽 `#F5C542`、蓝胳膊 `#3E7CC4`（按各家庭的角色卡换） |

**构图**
- 每页**一个视觉焦点**，主体约占画面 40–60%，四周留白
- 视线放在孩子的高度；向导在旁边带路，不抢主体
- 背景简单：一张桌面、一片地面、一面墙就够
- 横向 3:2（1536×1024）

**禁止**
- 光泽塑料感的 3D、CG 渲染感（这是最常见的「AI 味」）
- 霓虹色、过饱和、暗色调、复杂背景
- 生图画面里出现文字、字母、数字、水印（生图模型写字会乱码）；SVG 画面可以有不超过 3 处中文标注，字要大
- 模仿任何现成的动画公司或绘本画家的风格
- 吓人的特写（见 05「画面」）

**主角（孩子本人）**：**画风由这本书决定，主角按这本书的画风重新画。** 家长给的三视图、照片转的卡通形象，只用来锁定长相、发型和衣服，不继承它原来的画法（比如 3D）。小样见 `assets/styles/A4_protagonist_in_A1.jpg`。

## 二、生图路线：三种画风

生图时，把这一页的 `image_prompt` 和下面对应风格的**风格段**拼在一起，再加上「共用禁止」那一段。参考图（角色、主角）**只用来锁定身份，不继承画法**，要在提示词里写明。

### A1 · 淡彩手绘图纸（默认）

像建筑师手绘的剖面图：细钢笔线，略带手抖，颜色只淡淡铺几层，大部分是留白的纸。最有辨识度，和「拆解」最贴。适合所有年龄档。小样：`assets/styles/A1_pen_wash.jpg`

```
Style: an architect's restrained hand-drawn pen section with extremely light transparent watercolor. It must read first as a delicate ink drawing on mostly blank ivory paper: clear hairline dark sepia steel-pen contours, slightly trembling freehand lines, only a few pale transparent watercolor strokes, most areas left as unpainted paper. No heavy wash, no painterly shading. Generous white margins, visible paper texture. Warm, quiet, handmade.
```

实测经验：第一版颜色铺得太满，不像图纸；加上「must read first as an ink drawing」「most areas unpainted paper」「no heavy wash」之后才对。

### A2 · 水彩绘本

柔和的水彩，几乎没有线，颜色晕开、边缘柔和。最温柔，最像传统绘本。小样：`assets/styles/A2_watercolor.jpg`

```
Style: soft watercolor picture-book illustration, almost no outlines and no ink contours. Build forms with gentle translucent washes, pigment blooms and softly diffusing wet-on-wet edges, delicate warm natural light, visible watercolor paper grain. Restrained coral red, pale creamy yellow, muted green and blue. Calm, warm, visibly handmade.
```

### A3 · 黏土纸艺

像手工做出来的实物微缩模型：哑光黏土捏的角色，纸折出来的结构，柔和的棚拍光。触感最强，小班孩子最容易「看懂这是个东西」。微生物这类题也可以用：菌丝用棉絮、羊毛纤维来表现。小样：`assets/styles/A3_clay_paper.jpg`

```
Style: a photograph of a real handcrafted miniature diorama. Characters made of matte hand-kneaded clay with subtle finger impressions and imperfect edges; structures built from folded fibrous art paper with visible cut edges and paper grain; fine details like mold made from wool or cotton fibers. Soft diffuse studio lighting, warm off-white seamless backdrop, shallow depth of field while the main subject stays legible. Absolutely no smooth CGI plastic, no glossy toy surfaces.
```

### 共用禁止段（每张都加）

```
No text, letters, numbers, labels, watermark or signature anywhere. No glossy plastic 3D, no CG rendering, no neon, no oversaturated color, no dark scene, no complex background. One clear focal point. Do not imitate any existing animation studio or picture-book artist.
```

## 三、SVG 路线：三种画风

只能写代码的 agent 用 SVG 画。每种风格都有一份**可以直接照着写的源码**（`assets/styles/*.svg`），里面的滤镜、配色、线宽都可以复用。画布 `viewBox="0 0 1536 1024"`；向导用同一段代码每页复用（见 03）。

### B1 · 线稿淡彩（默认，和 A1 同一家族）

小样与源码：`assets/styles/B1_line_wash.jpg`、`B1_line_wash.svg`

- 线：深褐 `#4A3B2C`，2.5–3.5px，圆头圆角；加一个 `feTurbulence + feDisplacementMap`（scale 4–6）的滤镜，让线有一点手抖
- 色：在线稿**下面**另画一层淡色块，透明度 0.5–0.8，整体错开几个像素（像手工上色没对准），色块边缘也加一点扰动
- 底：纸色，加一层很淡的噪点当纸纹（透明度 ≤ 0.1）
- 放大圈：两道细线圈 + 虚线引线

### B2 · 积木几何

小样与源码：`assets/styles/B2_blocks.jpg`、`B2_blocks.svg`

- 平涂色块，不描边；圆角统一（8–18px）
- 每个物体 2–3 个色阶；阴影用同形状深一档的颜色错开 8–12px，不用模糊
- 最清楚、最醒目，适合小班；但最容易像课件，所以背景一定要简单，颜色守住调色板

### B3 · 剪纸拼贴

小样与源码：`assets/styles/B3_paper_cut.jpg`、`B3_paper_cut.svg`

- 每一层是一张「剪出来的彩纸」：形状边缘加扰动（scale 5–7）模拟毛边，再加柔和投影（模糊 4–6px、偏移 5–7px、透明度 0.3 左右）
- 底：米色纸加纤维纹理
- 层次靠叠放和投影表现，不靠描边

## 四、问卷里怎么问

问卷第 7 题「出什么」之后接一句：「想要哪种画风？」先说清当前 agent 能做哪一类（生图 / SVG），只列这一类的三种，附上小样让家长看。不选就用默认（生图 A1，SVG B1）。选好写进档案 `style`，以后每本书都用它，写进 `book.json` 的 `render.style`（例如「A1 淡彩手绘图纸」）。

## 五、画完以后

把全书各页和对应风格的小样放在一起看一遍：调色有没有跑、线条是不是同一种、有没有哪一页突然变成 3D 或者变暗。跑掉的那页重画。
