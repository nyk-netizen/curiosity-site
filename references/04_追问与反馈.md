# 04 · 追问与反馈（孩子读完以后）

> 什么时候读：第 2 步判断是追问时；第 8 步孩子读完以后。
> 来历：一个孩子听完圣诞节的故事，问爸爸「圣诞老人会死掉吗」；听完「红色为什么叫红色」，又追问「是人类本能的命名吗」。**好问题常常是读完一本书之后才冒出来的**。旧做法里孩子只能问一次，书读完就结束了；这里让孩子读完说的话，变成下一本的起点。

## 一本书读完会留下什么

`book.html` 最后一页会导出 `feedback.json`：

```json
{
  "book_title": "云里的大鼓是谁敲的？",
  "question": "为什么会打雷？",
  "date": "2026-10-11",
  "follow_ups_tapped": ["为什么总是先看到闪电，后听到雷？"],
  "child_words": "孩子自己说的话，家长代写，原话照录",
  "reaction": "loved | ok | bored | scared | confused",
  "parent_note": "家长的观察"
}
```

家长把它放回这本书的文件夹。没有导出也没关系，家长直接把孩子说的话告诉你，你来整理成同样的格式。

## 收到反馈后做三件事

### 1. 记进档案
在 `profile.json` 的 `history` 里追加一条：日期、文件夹、书名、`reaction`、`follow_ups_tapped`、`child_words`、`parent_note`。

### 2. 按反应调整下一本

| reaction | 意思 | 下一本怎么调 |
|---|---|---|
| `loved` | 喜欢 | 保持这个讲法和比喻方向 |
| `ok` | 一般 | 看 `parent_note`；没有就不调 |
| `bored` | 没兴趣 | 比喻换到他的兴趣方向（档案第 2 题）；页数往短里调 |
| `confused` | 没听懂 | 下一本每页只推进一步，少用抽象词；问家长是哪一页卡住了，那一页可以重做 |
| `scared` | 害怕了 | **先告诉家长**；问家长要不要把这个东西加进档案的「怕什么」，同意了再加。以后同类题按恐惧题规则处理（见 05） |

### 3. 把孩子的话当成下一本的候选
- `child_words` 里如果有问题，**原话**就是下一本的 `question.original`
- `follow_ups_tapped` 是孩子点过的追问口，也是候选
- 都列给家长，由家长决定做不做、先做哪个。不要自己挑一个就开始写

## 追问模式怎么写（`mode: follow_up`）

1. **读上一本**：上一本的 `book.json` 和 `feedback.json`。这是唯一允许读的其他书
2. **填好关联**：`continues_from` 写上一本的文件夹名；`question.original` 写孩子的追问原话
3. **同一个角色、同一种画风**：`guide` 原样沿用；生图路线带同一张参考图，代码画图路线复用同一个角色 SVG
4. **短**：通常 1 章 2–3 页就够，最多 3 章 8 页
5. **开头接上**：第一页用一句话连回上一本（「上次我们看到云里攒了好多电……」），让孩子知道这是接着讲
6. **不推翻前面讲过的内容**。如果孩子的追问暴露出上一本简化过头了，**明说**：「上次我们说得太简单了，其实……」，并在家长卡 `uncertain` 里写清楚上一本哪里简化了
7. 结尾照样留追问口，最后一页照样留给孩子

## 今天没有问题（`mode: no_question`）

孩子有时会说「我今天没有问题」。这也是一种回答，不要追着他要问题。

- 从孩子身边常见、但他可能没注意过的东西里出一题：钥匙为什么能开门、拉链怎么拉上的、电梯怎么知道停在哪层
- 优先选他档案里的兴趣方向；也可以从最近几本书的追问里挑一个他没点过的
- `question.original` 写你替他出的题，家长卡里写明「这是替孩子出的题，不是他问的」
- 封面上照样写「你问：……」不合适，所以这种书的封面问题可以写成「今天我们来想一想：……」（渲染脚本会根据 `mode` 处理）

## 最后一页

最后一页（`child_page`）永远留给孩子：

- `prompt` 写一句邀请，比如「你还想知道什么？说给爸爸妈妈听，他们会帮你写在这里」
- `child_words` 做书时留空。孩子读完后家长代写，原话照录，**你不要替孩子编一个结尾或追问**
- 孩子不说也可以，空着就是空着
