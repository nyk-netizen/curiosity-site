# 07 · 示例：「为什么会打雷？」

> 什么时候读：拿不准格式或分寸的时候。完整 JSON 在 `assets/sample_book.json`，这里只讲**为什么这样写**。
> 这是一本手写的样例，不来自任何真实孩子；向导角色「阿尺」也是为样例造的。**不要照抄它的情节和比喻**，你的书要从你这道题的研究里长出来。

## 写之前想清楚的三件事（对应 02）

| 问题 | 这本书的答案 |
|---|---|
| 核心答案一句话 | 云里的冰粒撞来撞去攒了电，电一下子放出来就是闪电，闪电把空气烫得猛地鼓起来，那一声就是雷 |
| 孩子的问题里有没有猜想 | 没有。但「怕打雷」很常见，所以定为恐惧题，`sensitive.level = notice` |
| 贯穿全书的建筑类比 | 雷雨云是一座高塔：冰粒在塔里上上下下，塔顶塔底攒着不同的电，闪电是塔和塔之间的「发光的桥」 |

## 三章怎么分

| 章 | 页 | 推进了哪一步 |
|---|---|---|
| 发现与走进去 | 2 | 从「轰隆隆」这个孩子听得到的现象开始 → 走进云塔，看到冰粒在撞 |
| 结构与它怎么工作 | 3 | 撞多了带电 → 电攒多了放出来是闪电 → 闪电烫空气，空气「嘭」地推开是雷。一页只推进一步 |
| 魔法时刻与回到生活 | 2 | 最神奇的一下：能**自己数出**雷有多远 → 回到生活：在屋里就安全 |

## 几个分寸

- **角色带路，但不抢主体**：阿尺是一把折尺，所以它的动作都和「量」有关：折成望远镜、量云塔、数秒、记数字。角色的特点就是它带路的方式
- **恐惧题落到「不可怕」和「可以做什么」**：最后一页不是「雷很危险」，而是「在屋里听就好」，外加一件孩子能做的事（数秒）。雷击伤人的内容不进正文，户外防雷常识写给家长
- **简化过的地方老实写出来**：云里怎么起电，学界还在研究，书里简化成「撞多了就带电」，家长卡 `uncertain` 里写明了；「数到 3 约 1 公里」也注明是估算
- **来源是真的**：两条都是美国国家气象局的页面，写进去之前打开核对过，书里的温度数字也按原文改过一次（最初写的「约 3 万摄氏度」不准，原文是 5 万华氏度，约 2.8 万摄氏度）
- **追问口接得上**：第一章讲到冰粒 → 追问「冰粒从哪来」；第二章讲到闪电和雷 → 追问「为什么先看到闪电」；第三章讲到安全 → 追问「闪电打到地上会怎么样」
- **最后一页空着**：`child_words` 是空字符串，等孩子读完由家长代写

## 渲染出来什么样

```bash
python3 scripts/validate_book.py assets/sample_book.json
python3 scripts/render_book.py assets/sample_book.json /tmp/sample.html
```

打开 `/tmp/sample.html`：封面 → 7 页正文（这份样例没有图片，画面位置显示中文画面说明）→ 每章后一张追问卡 → 留给孩子的最后一页 → 家长卡。
